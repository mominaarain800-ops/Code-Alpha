# Task 2: Phishing Awareness Training

## Objective
Teach users to identify phishing attempts, recognize social-engineering tactics, and take safe actions.

## How to use
Open `index.html` in a modern web browser. The training module works offline and includes:
- Definition and warning signs
- A fictional suspicious-message example
- Social-engineering tactics
- Prevention and response recommendations
- An interactive three-question quiz

## Privacy and safety
This is an awareness module only. It does not send emails, collect passwords, or track visitors.

## Suggested presentation summary
1. Define phishing.
2. Show warning signs: urgency, suspicious sender, links, attachments, and requests for secrets.
3. Explain social-engineering tactics.
4. Demonstrate safe verification and reporting.
5. Complete the quiz and discuss answers.
